# CineReel AI V1

V1 adds a real video workflow on top of the previous UI foundation:

- Select a video from Gallery
- Preview with Media3/ExoPlayer
- Choose an editing style
- Trim a 0–15 second segment
- Export the trimmed MP4 using Media3 Transformer
- Share the exported MP4

Important:
- This is an Android Studio source project, not an APK.
- AI beat detection, automatic clip selection, cinematic LUTs, transitions, captions, music syncing and true 9:16 export are not yet implemented.
- Those are the next development stage.

Open the project in Android Studio, sync Gradle, then build/run on an Android device.
